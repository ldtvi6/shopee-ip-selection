## 虾皮是怎么用IP做关联判断的？

虾皮官方没有公开过风控算法的细节，但做跨境IP服务的商家（比如IPdodo）整理出来的逻辑基本一致：IP是平台判断“这些账号背后是不是同一个人”时最直接的线索。落到具体场景，主要有三类：

1. **同IP多账号**。多个店铺账号频繁从同一个IP登录、操作，是最典型的关联信号，系统会把这些账号标记为风险账户。
2. **异常行为**。订单量突然暴涨、频繁修改账户资料，都会让账号进入风控视野。
3. **异常交易模式**。大量低价商品被异常购买，或者多个账号同时拍同一款商品，属于重点监控对象。

被盯上的后果分几档：轻则交易受限，比如限制大额交易、暂时不能上新和编辑商品；重则被塞进更严格的审核流程，要补交身份证明和交易凭证；再往上是直接封店。做店铺矩阵的话，一间出问题还可能牵连同IP下的其他店。

> 一条家庭宽带挂着两三家店，在平台眼里和“同一IP多账号”没有区别——你换了新电脑、新手机也没用，出口IP还是同一条。这是新手最早踩的坑之一。

## 独立IP怎么选：虾皮场景里真正要过的三道关

只看“独不独享”很容易买到不对口的东西。虾皮场景里，一个IP要过三道关才算能用。

### 第一道：归属地——原生IP和广播IP的差别

一台VPS的IP确实是你一个人用，但如果它是“广播IP”——IP资源注册在A国、实际部署在B国机房——平台看到的归属地就和你的店铺站点对不上。判断方法不难：用IP归属查询工具看注册国家，再用多地ping看实际落地位置，两边一致才算原生。LisaHost这类主打“原生IP”的商家，卖的就是注册地和部署地一致的IP，这也是本土店场景选它的核心理由。

### 第二道：类型与历史纯净度

IPdodo在讲虾皮关联的科普里给过一个简单办法：在ipinfo这类IP信息查询网站查一下，type一栏显示ISP的基本就是住宅IP。除了类型，还要看这个IP以前被谁用过——机房段的IP经常被回收再分配，如果前任拿它注册过一堆账号，你接手的就是一个有“案底”的IP。所以绑定店铺之前，先查IP的黑名单和历史记录，这一步花不了十分钟，能省掉后面很多麻烦。

### 第三道：和店铺类型的匹配度

这一道是多数教程没讲清楚的地方，得分两种情况：

- **本土店**：店铺开在泰国、马来西亚、菲律宾、越南、印尼这些站点，登录IP就应该长期落在对应国家。归属地漂到别的国家，是本土店被风控盯上的常见原因。
- **跨境店**：通过招商渠道入驻、从国内运营本身是正常状态，IP的关键在于固定、独享，而不是非得选境外节点。一间店一个稳定IP、不和其他店混用，基本要求就满足了。

顺带提一句：搜“独立IP”经常能看到讲搬瓦工的教程，它确实是老牌VPS商家，但产品线以美国等机房IP为主，没有东南亚本土节点，对虾皮本土店这个场景并不对口，选的时候注意区分。

## 拿到IP之后：把配置做对的五个步骤

核心思路一句话：一店一IP一环境，从第一次登录就固定下来，之后尽量少折腾。

1. **先验IP，再绑店**。查归属地和类型（type显示ISP为住宅IP），再用IP信誉查询确认没有历史污点。有问题趁没绑店先找商家换掉，别将就。
2. **注册或迁移时环境干净**。新店注册前把设备收拾好：浏览器无旧缓存、别挂公共WiFi，老生常谈但真有用。老店换IP的话，选店铺流量低峰期切换，切换前后操作习惯保持一致。
3. **一店绑定一套环境**。指纹浏览器里每个店铺单独一个配置文件，绑定各自的IP，cookie和本地存储完全隔离。手机端登虾皮App的，换网络前先彻底退出后台再操作。
4. **绑定之后少切换**。IP定下来就别频繁动，尤其不要挂着虾皮后台随意换网络。真要换节点，当成一次正式的环境迁移来做，而不是随手改个代理。
5. **定期自查**。隔段时间看看店铺有没有异常登录提醒、有没有被要求二次验证。平时把每次登录的IP、设备和时间记个简单台账，真出问题的时候能说清楚。
